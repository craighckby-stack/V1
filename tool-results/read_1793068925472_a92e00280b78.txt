    46→ 1. `src/app/api/health/route.ts`                       GET  — returns `{status, version:"4.1.0", timestamp, subsystems:{pipeline,governor,sanitizer,autonomousLoop,websocket}}`.

    48→ 3. `src/app/api/github/repo-tree/route.ts`             POST — calls `git/trees/{branch}?recursive=1`; filters blobs via the exact spec regex `\.(ts|tsx|js|jsx|json|md|py|go|rs|css|html|yaml|yml|sh|sql)$/i` and excludes `^(node_modules|\.git|\.next|dist|build|coverage)/`.     49→ 4. `src/app/api/github/fetch-file/route.ts`           POST — calls `/contents/{path}?ref={branch}`, base64-decodes `content` when `encoding==="base64"`. Returns `{content, sha, path}`.

    51→ 6. `src/app/api/github/batch-commit/route.ts`         POST — loops through `files[]`, commits each individually, returns `{success, committedCount, totalCount, results:[{path,success,sha?,error?}]}`. `success` is true only when `committedCount === totalCount`.
